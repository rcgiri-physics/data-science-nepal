# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, welcoming and patient — many contributors are teachers and
students. Harassment, discrimination (including by caste, ethnicity, gender, religion,
language or disability) and sharing of children's personal data are not tolerated.
Report concerns to rcgiri.physics@gmail.com. Maintainers may remove content or contributors
that violate these rules.
