# Beyond Grade 12 — where this can lead

> A taste, not a full course. **Verify every programme, entry rule, fee and scholarship on the official site before deciding** —
> offerings change. Programme names below are common categories, not an endorsement or a guarantee of availability.

## 1. What data work looks like after school
| Area | Typical work | Skills from this curriculum |
|---|---|---|
| Public health | Surveillance dashboards, facility planning | Rates, mapping, bias audit |
| Climate and environment | Trend analysis, hazard maps, air quality | Time series, uncertainty, geospatial |
| Education | Enrolment analysis, learning assessment | Tables, SQL, communication |
| Business and finance | Forecasting, customer analysis | Regression, evaluation, dashboards |
| Government and NGOs | Evidence for planning and budgets | Reproducibility, ethics, memos |
| Technology | Data engineering, machine learning | Python, SQL, Git, ML workflow |

## 2. Study pathways (categories to explore)
* **Computing:** Computer Science / IT / Software programmes (e.g. BSc CSIT, BIT, BCA, BE Computer or Software — check universities' current lists).
* **Statistics and mathematics:** Statistics, Applied Mathematics, Actuarial science.
* **Economics and social science:** Economics, Public Policy, Demography, Sociology (data-heavy).
* **Health and environment:** Public Health, Environmental Science, Geoinformatics / Remote Sensing, Agriculture.
* **Abroad:** many universities offer Data Science, Statistics and Analytics degrees; compare curriculum, language requirements, costs, and scholarships.
* **Graduate study:** MSc in Data Science / Statistics / AI, after a relevant first degree.

## 3. Free next steps (internet needed)
* [CS50x](https://cs50.harvard.edu/x/) (Harvard) and its Nepal community — programming foundations.
* [Kaggle Learn](https://www.kaggle.com/learn) — short practical courses in Python, pandas, SQL, ML.
* [Khan Academy Statistics and probability](https://www.khanacademy.org/math/statistics-probability).
* [freeCodeCamp](https://www.freecodecamp.org/) — data analysis with Python.
* Local communities (explore, verify before joining): CoSoG Nepal, Open Knowledge Nepal, Code for Nepal, NAAMII, NIC.

## 4. Ethics you carry with you
Consent, privacy, fairness, honesty about uncertainty, crediting sources, and not letting a model decide what people should.
