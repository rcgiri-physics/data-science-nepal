# Lesson anatomy (every lesson, every grade)

One lesson = one 40/45-minute period.

| Block | Time | What happens |
|---|---|---|
| **Hook** | 5 min | A local question ("Is it hotter in Biratnagar than in Jumla — by how much?"). Predict first. |
| **Concept** | ≤ 5 min | One idea only. Teacher talk or a ≤ 4-min optional video. |
| **Activity** | 20 min | PRIMM for code (Predict → Run → Investigate → Modify → Make); hands-on for no-code. |
| **Check** | 5 min | 3 retrieval questions (one recalls the *previous* lesson). |
| **Reflect** | 2 min | "What surprised me? Who is missing from this data?" |
| **Extension** | optional | Stretch task or home task (paper-only option always provided). |

Every lesson also carries:
* **If no computers / if no internet** note for the teacher.
* **Common misconceptions**.
* **Glossary** terms (English / नेपाली).
* **Sources** for any real data.

## PPDAC headings in projects
**P**roblem · **P**lan · **D**ata · **A**nalysis · **C**onclusion — the same five headings from Grade 8 to 12.

## Scaffolding fade
Notebooks fade from fill-in-the-blank (Gr 9) → partial skeleton (Gr 10) → blank with checklist (Gr 11–12).
