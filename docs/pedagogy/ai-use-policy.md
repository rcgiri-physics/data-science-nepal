# Responsible AI-assistant use (students and teachers)

AI assistants can be good tutors and poor shortcuts. Rules for this curriculum:

1. **Explain, don't answer.** Ask the assistant to explain an idea or a error message, not to write the whole solution.
2. **Disclose.** In every project write one line: "AI help used for: ___" (or "none").
3. **Own it.** Assessment always includes an **oral check**: the student explains their code/graph/conclusion
   without the assistant. If you cannot explain it, it does not count as your work yet.
4. **Verify.** Assistants invent facts, columns and sources ("hallucination"). Check every number against the dataset card.
5. **Protect people.** Never paste names, phone numbers, photos or survey rows about real classmates into a tool.
6. **Offline fallback.** Every task works without AI or internet.

## Prompt card (print and keep)
* "Explain what `groupby` does using an example about districts."
* "My code gives this error: ___. Don't fix it — give me a hint about where to look."
* "Check my interpretation of this graph: ___. What am I missing?"

## Teacher notes
Grade 10+ has a unit on AI literacy: what a model is, training data, bias, hallucination, and who benefits or is harmed.
