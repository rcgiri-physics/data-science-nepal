# How to credit this work

Reuse is welcome and free. The only condition is **credit** (CC BY 4.0).

**Copy-paste credit line**

> "Data Science for Nepal's Schools (डेटा विज्ञान / Data Science Nepal)" by Giri Ramchandra
> and contributors, licensed CC BY 4.0. Source: the repository URL (set when published)

If you changed the material, add: *"Adapted from the original; changes were made."*

**Citing in academic or policy documents:** use [CITATION.cff](CITATION.cff)
(GitHub's "Cite this repository" button gives BibTeX/APA).

**Dataset credit:** each dataset has its own source and licence — credit the data
publisher as written in the dataset card.
