# Unit project — Story and memo

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Turn one analysis into a memo and a chart.

## Plan
Audience and action.

## Data
District table (synthetic/real).

## Analysis
One finding.

## Conclusion
Memo + chart + 3-minute talk.

## Hand in
Memo + figure.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
