# Grade 12 — Data scientists II (modelling and communicating)

**Tools:** scikit-learn, pandas, Streamlit, Git/GitHub (Django optional) · **Units:** 8 · **Lessons:** 24 (+ projects)

Grade 12 is about *modelling and communicating*: the supervised machine-learning workflow, regression and classification,
evaluation metrics, overfitting, a fairness audit, feature engineering, data storytelling, and a community **capstone** with a real
"client" (ward office, health post, school, NGO). Health examples use the **synthetic** table (real DHS data cannot be redistributed);
every notebook ends by asking what could go wrong for real people. Django is an optional stretch for students who already know web basics.
