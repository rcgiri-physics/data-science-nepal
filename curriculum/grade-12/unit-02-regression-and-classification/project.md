# Unit project — Explain a prediction

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Pick one regression and one classification question.

## Plan
Features and risks.

## Data
Synthetic health table.

## Analysis
Fit both; compare with baselines.

## Conclusion
Explain results to a non-expert.

## Hand in
Notebook + one-page explanation.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
