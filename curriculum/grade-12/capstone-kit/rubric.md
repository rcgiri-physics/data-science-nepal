# Capstone rubric (four levels: 1 Beginning · 2 Developing · 3 Secure · 4 Extending)

| Criterion | 3 Secure looks like | 4 Extending adds |
|---|---|---|
| **Client question** | Question and success measure agreed with the client; decision stated | Anticipates how the answer could change the decision |
| **Data & ethics** | Sources, licences, consent, cleaning log; data agreement followed | Audits who is missing; minimises data collected |
| **Analysis** | Baseline, correct method, validation; test used once | Compares alternatives; checks sensitivity |
| **Fairness audit** | Group comparison with sizes; limits stated | Proposes mitigation with the community |
| **Communication** | Action title, honest chart, 1-page memo in plain language | Presents uncertainty clearly; client can act on it |
| **Reproducibility** | README, versions, seed; peer reran it | Git history shows steps; tests/asserts |
| **Teamwork & honesty** | Roles shared; AI use disclosed; oral check passed | Mentors others; documents decisions |

Weighting suggestion: analysis 25%, client question 15%, data & ethics 20%, communication 20%, reproducibility 10%, teamwork 10%.
Always include a 3-minute **oral check** per student.
