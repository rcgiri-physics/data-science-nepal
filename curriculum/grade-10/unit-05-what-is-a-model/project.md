# Unit project — Model vs baseline

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Can the k-NN beat the baseline on the health table?

## Plan
State what you predict and from which features.

## Data
Synthetic health table.

## Analysis
Baseline, k-NN with 3 values of k.

## Conclusion
Say whether the model is useful and what could go wrong.

## Hand in
Notebook + half-page ethics note.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
