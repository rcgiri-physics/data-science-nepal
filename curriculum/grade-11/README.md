# Grade 11 — Data scientists I (uncertainty, time and space)

**Tools:** pandas, SQL, folium/GeoPandas, seaborn, Git · **Units:** 8 · **Lessons:** 24 (+ projects)

Grade 11 adds *uncertainty*, *time* and *space*: working with bigger tables, SQL window functions, bootstrap and permutation ideas,
regression with interpretation, seasonality, simple geospatial thinking, and reproducible workflows with Git. Aligned as an
enrichment bridge to NEB Computer Science (databases, programming), not a replacement. Notebooks run offline on **synthetic** tables
or on data generated inside the notebook.
