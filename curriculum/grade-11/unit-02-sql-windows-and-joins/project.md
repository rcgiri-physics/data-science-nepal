**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Which districts dominate each province on a chosen indicator?

## Plan
Choose an indicator and decide rate vs count.

## Data
District + schools tables.

## Analysis
Window query + chart.

## Conclusion
Describe concentration with numbers and one limit.

## Hand in
Notebook + paragraph.
