# Unit project — How sure are we?

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Estimate a mean with its uncertainty.

## Plan
Choose the variable and the sample size.

## Data
Health table (synthetic).

## Analysis
Bootstrap interval for 3 sample sizes.

## Conclusion
One correct interpretation and one limit.

## Hand in
Notebook + paragraph.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
