# Unit project — Same question, SQL and pandas

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Answer one district question twice.

## Plan
Choose a question that needs a filter and a group.

## Data
District table.

## Analysis
Write the SQL query and the pandas code; confirm they give the same answer.

## Conclusion
Explain which you preferred and why.

## Hand in
Notebook with both versions and a comparison sentence.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
