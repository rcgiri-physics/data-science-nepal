# Unit project — Clean it and log it

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Make the messy table trustworthy.

## Plan
List every problem you see before changing anything.

## Data
Messy air-quality table.

## Analysis
Fix each problem; count rows before and after.

## Conclusion
Write the cleaning log and one sentence on what could still be wrong.

## Hand in
Cleaned file + cleaning log (original kept).

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
