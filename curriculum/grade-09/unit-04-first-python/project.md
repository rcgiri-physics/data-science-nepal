# Unit project — My first data script

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Choose a question about the class survey.

## Plan
Decide which list you need and which summary.

## Data
Class survey (synthetic or your own).

## Analysis
Write a loop and a function that answer the question; test with a small list.

## Conclusion
Explain what the code does line by line (oral check).

## Hand in
Notebook + 2-minute oral walkthrough.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
