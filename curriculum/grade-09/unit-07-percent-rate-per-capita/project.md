# Unit project — Rate detective

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Find a place where a count and a rate tell different stories.

## Plan
Choose one indicator and denominator.

## Data
District + schools table.

## Analysis
Rank by count and rate; chart both.

## Conclusion
Explain the difference in two sentences.

## Hand in
Short report with both rankings.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
