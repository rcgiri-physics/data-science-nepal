# Unit project — One chart, one claim

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Choose a claim about districts that a chart can support.

## Plan
Pick the right chart type and justify it.

## Data
District table.

## Analysis
Draw the chart with title, axes, units, source.

## Conclusion
Write the caption: claim, evidence, one limit.

## Hand in
Chart image + caption + code.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
