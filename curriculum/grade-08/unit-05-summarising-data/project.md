# Unit project — What's typical in our class?

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
What is a typical travel time, sleep time or height in our class?

## Plan
Choose two numerical variables.

## Data
Use your class table.

## Analysis
Compute mean, median, mode, range; draw dot plots; mark outliers.

## Conclusion
State which summary you would report and why.

## Hand in
Calculations + dot plots + one 'typical value' sentence.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
