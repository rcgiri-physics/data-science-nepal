# Unit project — Two places, fair comparison

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
Which of two districts (or belts) does better on one indicator?

## Plan
Pick an indicator from the district table and one comparison.

## Data
District table extract (synthetic, or real table if your teacher fetched it).

## Analysis
Compute rates; compare medians; graph side by side.

## Conclusion
Write a fair comparison sentence with numbers and one caveat.

## Hand in
Calculation sheet + one graph + sentence.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
