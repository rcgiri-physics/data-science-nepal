# Worksheet 1 — Sort the cards (Lesson 1)

Print, cut into cards, and give each group a set. Sort into **numerical** and **categorical**; argue about the tricky ones.

| # | Card | Teacher answer |
|---|---|---|
| 1 | Height of a student (cm) | numerical |
| 2 | Mother tongue | categorical |
| 3 | Ward number | categorical (a label; averaging is meaningless) |
| 4 | Shoe size | numerical (counted in steps) |
| 5 | Travel by bus or on foot | categorical |
| 6 | Rainfall in July (mm) | numerical |
| 7 | Number of siblings | numerical (count) |
| 8 | Favourite subject | categorical |
| 9 | Roll number | categorical (a label) |
| 10 | Minutes to reach school | numerical |
| 11 | Village or tole name | categorical |
| 12 | Hours of sleep last night | numerical |
| 13 | Eye colour | categorical |
| 14 | Temperature in °C at noon | numerical |
| 15 | Grade (8, 9, 10…) | categorical here (a label) — can be discussed as ordered |
| 16 | Marks out of 100 | numerical |
| 17 | School type (public/private) | categorical |
| 18 | Number of books at home | numerical |
| 19 | Phone number | categorical (a label) |
| 20 | Month of birth | categorical (ordered) |

**Discussion prompt:** which cards were hard? What test can you use? *(Can I add or average it and still get a meaningful answer?)*
