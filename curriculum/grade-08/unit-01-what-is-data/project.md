# Unit project — My data portrait

**Time:** 2 periods + homework. **Groups of 3** with roles: data steward, analyst/driver, storyteller (rotate).

## Problem
What facts about our class can we record, and what question could they answer?

## Plan
List 5 variables (at least 2 numerical, 2 categorical). Decide units.

## Data
Each student fills one row on paper using a code (S01…), not their name.

## Analysis
Count the categories; find the smallest and largest value of each numerical variable.

## Conclusion
Write two sentences: one thing the data say, one thing they cannot tell us.

## Hand in
One class table + a short paragraph: what is a row, a column, a unit.

**Rubric:** the six-criterion four-level rubric in `docs/pedagogy/assessment.md`. **AI help:** disclose in one line.
