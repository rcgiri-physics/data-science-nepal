## Competitions: how to use them well

Competitions teach a lot — evaluation, validation, feature engineering — but leaderboards reward tiny gains that rarely
matter in practice. Use them to learn: read top solutions after the competition, write up what you learned, and remember
that real projects start with a question and a client, not a fixed dataset and a metric.

## Learning on a slow or expensive connection

* Download videos and lecture notes when you have good internet (many courses allow this); read PDFs offline.
* Kaggle notebooks and Colab run in the cloud — your computer can be old.
* JupyterLite and local Python run offline once installed.
* Prefer text tutorials and books to videos when data is costly.
* Study groups can share downloads (respecting licences).
