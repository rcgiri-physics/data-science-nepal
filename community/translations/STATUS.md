## How to help
1. Copy `chapter.md` to `chapter.ne.md` (or `chapter.<lang>.md` for another language).
2. Keep headings and code identical; translate prose; keep SQL and Python keywords in English.
3. Use the glossary; propose glossary fixes in the same pull request.
4. Label the pull request `translation` and `needs-teacher-review`.
