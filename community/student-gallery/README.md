# Student gallery

Accepted projects appear here **with consent**. Each entry is a folder `YYYY-school-code-title/` containing:

* `README.md` — question, method, claim, limits, data sources, AI-use line;
* the poster or notebook (no student names; use first name only if guardians agreed in writing);
* `CONSENT.md` — who consented to what (kept without private details).
