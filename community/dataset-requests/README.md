# Dataset and problem requests

Have a dataset or a real problem (ward, school, health post, farm cooperative)? Open a **new-dataset** or **new-lesson** issue
using the templates. You do not need to code. We will ask: source, licence, columns, which grade, and ethical concerns.

Rules: no personal data; no data that needs registration to obtain; licence must allow reuse (CC BY / CC0 / ODbL with credit).
